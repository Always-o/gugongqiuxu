# 依赖清单

## 结论先行

**运行时第三方依赖：0 个。** 没有 npm 包、没有框架、没有 CDN、没有字体服务、没有远程图片、没有后端接口、没有 API Key。
`package.json` 中的 `dependencies` 与 `devDependencies` 均为空对象，`npm install` 不是必需步骤。

---

## 1. 清单总表

| 类别 | 依赖 | 版本要求 | 是否必需 | 用途 |
| --- | --- | --- | --- | --- |
| 前端运行时库 | 无 | — | — | 全部用浏览器原生能力 |
| 构建工具 | 无 | — | — | 无打包/编译步骤，源码即可运行 |
| 外部资源 | 无 | — | — | 图片由 SVG / Canvas 生成，字体用系统字体栈 |
| 后端 / 数据库 | 无 | — | — | 数据写在 `js/data.js` 的结构化对象里 |
| 本地预览（可选） | Node.js | >= 18 | 可选 | `npm start` 运行 `scripts/serve.mjs` |
| 本地预览（可选） | Python | >= 3.8 | 可选 | `python3 -m http.server` |
| 代码托管 | GitHub / Gitee | — | 部署时需要 | 公开仓库 + 静态页面托管 |
| 版本管理 | Git | 较新版本 | 协作时需要 | 提交历史与版本回溯 |

`package.json` 只用来声明元信息和三个脚本：

| 脚本 | 命令 | 说明 |
| --- | --- | --- |
| `npm start` | `node scripts/serve.mjs` | 启动本地静态服务（默认 8788） |
| `npm run serve` | 同上 | 别名 |
| `npm run check` | `node --check` × 5 | 对预览脚本与四个前端 JS 做语法检查 |

`scripts/serve.mjs` 只 `import` 了 Node 标准库：`node:http`、`node:fs`、`node:fs/promises`、`node:path`、`node:url`。

## 2. 浏览器原生 API 依赖

页面功能依赖以下浏览器标准能力（不需要安装，但需要浏览器支持）：

| API | 使用位置 | 用途 | 缺失时的表现 |
| --- | --- | --- | --- |
| Canvas 2D（`getImageData` / `putImageData` / `toDataURL`） | `js/ai.js`、`js/app.js` | 风格迁移、落叶粒子、海报合成与 PNG 导出 | 不降级，现代浏览器均支持 |
| SVG DOM（`createElementNS`） | `js/scene.js` | 程序化绘制太和殿、角楼、御花园、金水河 | 不降级 |
| `IntersectionObserver` | `js/app.js` | 分节入场揭示动画 | 需现代浏览器 |
| Pointer / Mouse / Touch 事件 | `js/app.js` | 对比滑杆拖拽、鼠标秋风 | — |
| Web Speech `speechSynthesis` | `js/app.js` | 诗词与答问朗读 | 静默降级 |
| Web Speech `SpeechRecognition` / `webkitSpeechRecognition` | `js/app.js` | 语音提问 | 降级为文字输入 |
| `URL.createObjectURL` / `revokeObjectURL`、`new Image()` | `js/ai.js`、`js/app.js` | 本地图片读取与结果下载 | 现代浏览器均支持 |
| Canvas `toDataURL` / `toBlob` | `js/app.js` | 风格迁移结果与诗画海报导出 | 现代浏览器均支持 |
| `devicePixelRatio` / `requestAnimationFrame` | `js/app.js` | 高分屏粒子渲染 | — |
| CSS3 动画、自定义属性、媒体查询 | `css/style.css` | 视觉与响应式 | — |

## 4. 内部模块依赖（非第三方）

四个 JS 文件按顺序由 `index.html` 末尾同步加载，前者暴露全局命名空间给后者使用：

| 加载顺序 | 文件 | 挂载 | 被谁使用 |
| --- | --- | --- | --- |
| 1 | `js/data.js` | `window.DATA` | `js/app.js`、`js/ai.js` |
| 2 | `js/scene.js` | `window.Scene` | `js/app.js` |
| 3 | `js/ai.js` | `window.AI` | `js/app.js` |
| 4 | `js/app.js` | （无导出，负责启动） | — |

`window.AI` 对外接口：`STYLES`、`stylize`、`generatePoem`、`ask`、`poster`、`loadImageFile`、`currentTerm`、`phaseOfTerm`、`PLACES`。
调整加载顺序会破坏依赖，改动时请勿随意重排。

## 5. 如何自行核验「零依赖」

```bash
# 1) package.json 中没有第三方包
node -e "const p=require('./package.json');console.log(p.dependencies,p.devDependencies)"

# 2) 页面源码中没有外部 URL / @import / CDN（SVG 命名空间除外）
grep -RnoE 'https?://|@import' index.html css js | grep -v 'www.w3.org/2000/svg'

# 3) 预览脚本只引用 Node 标准库
grep -n '^import' scripts/serve.mjs

# 4) 断网验证：关闭网络后打开 index.html，九个分节与四个工坊仍可操作
```

> 说明：`css/style.css` 中出现的 `data:image/svg+xml,...` 是内嵌的数据 URI（用来生成纸纹噪点），不是外部请求；`http://www.w3.org/2000/svg` 是 SVG 标准命名空间字符串，也不会产生网络访问。
