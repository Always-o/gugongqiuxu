# 故宫秋序

> 一城秋序，半部京华 —— 按初秋、仲秋、暮秋三段时令重游紫禁城的秋日数字雅集。

**在线预览**：<https://always-o.github.io/gugongqiuxu/>
**代码仓库**：<https://github.com/Always-o/gugongqiuxu>（Public）

## 一、项目介绍

故宫的秋天不是一天来的。处暑起风，秋分月圆，霜降之后银杏一夜黄透；从 8 月下旬到 11 月下旬，大约九十来天，宫墙换三次颜色。

常见的故宫专题页习惯按「建筑 / 文物 / 书画」分类罗列，看完容易记不住。**故宫秋序**改成按时间编目：跟着节气往下走，一格节气配一处建筑、一件器物、一句诗，把九十来天串成一条线，而不是一堆词条。

站点是**纯前端、零依赖、零外部资源**的单页应用，断网也能完整运行，适合答辩现场直接演示。内容规模：

| 内容 | 数量 | 说明 |
| --- | --- | --- |
| 秋序三时 | 3 | 初秋 / 仲秋 / 暮秋，各配日期区间、色谱、光影建议 |
| 秋景场景 | 4 | 太和殿、角楼、御花园、金水河，均由 SVG 程序化绘制 |
| 秋季文物 | 6 | 卡片式细读，点击展开释读弹窗 |
| 秋诗 | 7 | 真实古诗，附时令注解 |
| 节气 | 6 | 按中学美育课深浅撰写讲解 |
| 导览路线 | 3 | 按拍摄时段与动线组织 |
| 工坊模块 | 4 | 秋景生成、古画活化、诗词创作、节气问答 |

页面共九个语义分节：首屏「故宫秋序」+ 八个导航版块（秋序三时、秋景万象、秋物藏珍、秋诗雅韵、创作工坊、秋序课堂、秋日导览、关于作品）。

### 四个可以当场试的工坊模块

1. **秋景生成**：上传一张照片，浏览器内做像素级风格迁移（故宫工笔 / 古风摄影 / 水墨长卷 / 落枫插画），可下载 PNG。照片不上传服务器。
2. **古画活化**：拖拽滑杆对比「修复前 / 修复后」，查看线稿提取与设色逻辑。
3. **诗词创作**：按七言绝句格律生成秋诗，约束韵部、起式、仄收、避重韵与跨句复字，可一键合成诗画海报并导出。
4. **节气问答**：本地知识库关键词检索，回答节气、建筑、诗词相关问题，支持语音输入与朗读。

> **说明**：本站的「AI」指**浏览器内的本地算法引擎**（Canvas 像素运算、格律约束生成、关键词检索），不调用任何大模型或云端接口，也不需要 API Key。文物文案为科普示意，正式引用请以故宫官方著录为准。

## 二、技术架构

### 2.1 分层结构

```
┌─────────────────────────────────────────────────────────┐
│  表现层  index.html + css/style.css                       │
│  语义化单页 · 设计令牌 · CSS3 动画 · 响应式 · 落叶粒子     │
└───────────────────────┬─────────────────────────────────┘
                        │ DOM 事件 / class 切换
┌───────────────────────▼─────────────────────────────────┐
│  交互层  js/app.js                                        │
│  路由式版块渲染 · IntersectionObserver 入场 · 拖拽滑杆     │
│  Pointer Events · Web Speech（TTS / ASR）· 启动封装       │
└──────────┬────────────────────────┬─────────────────────┘
           │ 调用                    │ 读取
┌──────────▼──────────────┐  ┌──────▼────────────────────┐
│  算法层  js/ai.js        │  │  数据层  js/data.js        │
│  Canvas 2D 像素运算      │  │  节气 / 文物 / 诗库 / 路线  │
│  Sobel 边缘检测          │  │  结构化对象，集中维护       │
│  绢本色谱映射            │  └────────────────────────────┘
│  格律引擎 / 检索 / 合成  │  ┌────────────────────────────┐
└─────────────────────────┘  │  场景层  js/scene.js       │
                              │  SVG 程序化建筑与天际线     │
                              └────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────┐
│  输出层  Canvas.toDataURL · PNG 下载 · Web Speech 朗读     │
└─────────────────────────────────────────────────────────┘
```

### 2.2 技术选型与理由

| 层次 | 技术 | 为什么这样选 |
| --- | --- | --- |
| 页面 | 原生 HTML5 语义标签 + 锚点分节 | 无构建步骤，评审可直接打开源码 |
| 样式 | 原生 CSS3，`:root` 设计令牌 | 主题色集中管理，响应式无需预处理器 |
| 场景 | 程序化 SVG 生成 | 无图片素材依赖，建筑轮廓可随节气/时段参数化 |
| 交互 | 原生 JavaScript（IIFE 隔离） | 零框架，避免打包与版本兼容问题 |
| 图像算法 | Canvas 2D `getImageData` / `putImageData` | 像素级控制，风格迁移全程本地 |
| 语音 | Web Speech API（TTS / ASR） | 浏览器原生，无需 SDK |
| 内容 | `window.DATA` 结构化对象 | 文案与逻辑分离，现场改词不用碰 JS 逻辑 |

**脚本加载顺序**（`index.html` 末尾，无 `defer` 依赖顺序）：
`js/data.js` → `js/scene.js` → `js/ai.js` → `js/app.js`，分别挂载 `window.DATA`、`window.Scene`、`window.AI`，最后由 `app.js` 统一启动。

**关键实现**：
- 建筑屋顶剖面按「脊部陡、檐口平、翘角」建模，避免生成斗笠状轮廓；
- 风格迁移用 Sobel 边缘检测 + 明度映射到绢本色谱（RAMP 映射，避免逐通道量化产生色带）；
- 诗词生成按 4 个韵部 × 3 类句式 + 起承转合约束，含「首句入韵 / 不入韵」两种起式、韵脚去重与二十八字内同字复用过滤。

## 三、安装与运行

本项目**没有构建步骤**，不需要 `npm install`。以下三种方式任选其一。

### 方式 A：直接打开（最快）

双击 `index.html` 用浏览器打开即可。除浏览器的语音识别在 `file://` 下可能受限外，其余功能（含图片上传、风格迁移、海报导出）均可正常使用。

### 方式 B：Node 本地服务（推荐，可配环境变量）

要求 Node.js >= 18（仅用标准库，不装任何包）：

```bash
cd gugongqiuxu
cp .env.example .env        # 可选，不复制也能跑
npm start                   # 等价于 node scripts/serve.mjs
```

打开 <http://127.0.0.1:8788/>。`PORT`、`HOST`、`SITE_ROOT` 可在 `.env` 中修改，详见 [docs/环境配置.md](docs/环境配置.md)。

### 方式 C：Python 本地服务

```bash
cd gugongqiuxu
python3 -m http.server 8788 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8788/index.html>。

### 运行自检

```bash
npm run check               # 对全部 JS 做语法检查
```

手工验收清单：首页落叶与场景正常 → 拖开「盛夏 / 入秋」对比条 → 上传照片做风格迁移并下载 → 作诗并导出海报 → 节气问答（语音可选）→ 点击文物卡片展开弹窗 → 缩到手机宽度检查响应式。

### 浏览器兼容

| 浏览器 | 页面与图像功能 | 语音（TTS / ASR） |
| --- | --- | --- |
| Chrome / Edge（推荐） | 支持 | 支持 |
| Safari / Firefox | 支持 | 朗读可用，语音识别不可用 |

语音识别依赖 `SpeechRecognition` / `webkitSpeechRecognition`，缺失时页面会自动降级为文字输入，不影响其他功能。

- **环境变量模板**：[`.env.example`](.env.example)。本项目没有后端、没有第三方 API、没有密钥，**没有任何必填环境变量**；模板中的 `PORT` / `HOST` / `SITE_ROOT` 只作用于本地预览脚本。

```bash
grep -RnoE 'https?://|@import' index.html css js | grep -v 'www.w3.org/2000/svg'
```
